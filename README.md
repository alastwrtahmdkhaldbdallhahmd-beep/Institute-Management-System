# Institute-Management-System
# 🎓 Institute Management System (نظام إدارة المعهد التقني)

نظام متكامل لإدارة المعاهد والكليات التقنية والمهنية تم تطويره بلغة **Java** باستخدام واجهات **Java Swing** وقواعد بيانات **MySQL**.

---

## 🚀 المميزات الرئيسية (Features)

* **إدارة الطلاب:** إضافة، تعديل، حذف، واستعراض بيانات الطلاب التفصيلية.
* **إدارة الكادر التدريسي:** تسجيل وتحديث بيانات المعلمين والمحاضرين.
* **سجل الحضور والغياب:** متابعة يومية لفترات الحضور والغياب للطلاب والمعلمين.
* **تقارير وكشوفات قابل للطباعة:** طباعة تقارير الحضور والغياب فورياً عبر الطابعة.
* **إدارة الرسوم الدراسية:** تسجيل وإدارة دفع أقساط الرسوم الدراسية للطلاب.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Language:** Java (JDK 21)
* **GUI:** Java Swing & AWT
* **Database:** MySQL (via XAMPP / MariaDB)
* **Connectivity:** JDBC (MySQL Connector/J)

---

## ⚙️ طريقة التشغيل (Setup Instructions)

1. قم بفك الضغط عن ملف المشروع `المعهد الفني التجاري.rar`.
2. قم باستيراد ملف قاعدة البيانات `ums.sql` إلى **phpMyAdmin** بداخل خادم MySQL.
3. افتح المشروع في بيئة التطوير (NetBeans / Eclipse / VS Code).
4. أضف مكتبة `mysql-connector-j.jar` إلى **Libraries** الخاصة بالمشروع.
5. شغل ملف `Splash.java` للبدء.

* **بيانات الدخول الافتراضية:**
  * **اسم المستخدم:** `admin`
  * **كلمة المرور:** `admin`
